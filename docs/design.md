# 统一视觉与场景约定

固定视角像素卡通广场是入口，清晰列表是实际操作页面。当前提供 CSS 绘制的简化房子、树、角色和统一浅绿/奶油色 UI，供三人继续完善。

- 四栋房子固定为二手、搭子、失物、自己的家。技能互助放搭子小屋，中心公告是布告栏，消息属于底部。
- 主场景、页面头部、分类标签使用同一套颜色与像素装饰；阅读正文保持普通清晰字体，不把长段中文画成像素。
- 二手和失物保留真实照片；房子与角色用原创资产，不直接使用蛋仔等已有游戏素材。
- 页面复用 ContentCard、FeedList、DemoNotice、EmptyState，主题集中在 styles/theme.scss；新增组件不要各写一套不一致的按钮和弹窗。
- 最终玩家移动属于 A 的后续任务；骨架走动是演示动画，不声称实时多人在线。
- 样式使用 uni-app 通用组件，避免只在浏览器可用的 DOM / canvas API。新动画与图片资源需同时检查 H5、微信真机和资源体积。
