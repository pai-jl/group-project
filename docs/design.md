# 统一视觉与场景约定

固定视角像素卡通广场是入口，清晰列表是实际操作页面。第一阶段沿用 A 提供的旧原型背景和豆豆造型，迁移为 uni-app 图片与 CSS 组件，搭配现有浅绿/奶油色 UI。资源与编辑记录见 [plaza-assets.md](plaza-assets.md)。

- 四栋房子固定为二手、搭子、失物、自己的家。技能互助放搭子小屋，中心公告是布告栏，消息属于底部。
- 主场景、页面头部、分类标签使用同一套颜色与像素装饰；阅读正文保持普通清晰字体，不把长段中文画成像素。
- 二手和失物保留真实照片；房子与角色用原创资产，不直接使用蛋仔等已有游戏素材。
- 页面复用 ContentCard、FeedList、DemoNotice、EmptyState，主题集中在 styles/theme.scss；新增组件不要各写一套不一致的按钮和弹窗。
- 背景按完整宽高比展示，手机不裁掉左右建筑；四个入口至少 44px 高，点击招牌直接进入模块。
- 玩家点击步道后沿闭合路线行走，抵达停下；点击建筑等其他位置时目标投影到最近步道，路径避开中心树岛。可暂停/继续、回到起点，离开广场后停止计时；H5 尊重减少动态效果设置，初始暂停。
- 另外三个豆豆是本地装饰角色，不代表真实用户或实时在线人数。
- 搭子/技能求助共用筛选面板和分段入口；快捷类别只是建议，手动完整类别仍可搜索，状态与关键词可以组合并重置。
- 样式使用 uni-app 通用组件，避免只在浏览器可用的 DOM / canvas API。新动画与图片资源需同时检查 H5、微信真机和资源体积。
